# Marathon Registration System (ระบบลงทะเบียนการแข่งขันมาราธอน)

เว็บแอปพลิเคชันสำหรับการจัดการและลงทะเบียนการแข่งขันวิ่งมาราธอน พัฒนาด้วย **PHP** และ **MySQL** โดยใช้เทคโนโลยี **PDO** เพื่อความปลอดภัยในการจัดการฐานข้อมูล 
เว็บแอปพลิเคชันนี้เป็นผลงานจากการแข่งขันทักษะวิชาการ พ.จ.น.ก. สัมพันธ์ ครั้งที่ 46 มหาวิทยาลัยราชภัฏหมู่บ้านจอมบึง จัดเก็บไว้เพื่อเป็นแฟ้มสะสมผลงาน (Portfolio)

*หมายเหตุ: ข้อมูลทั้งหมดในระบบเป็นข้อมูลจำลอง (Mock Data) เพื่อการทดสอบเท่านั้น ไม่มีข้อมูลส่วนบุคคลจริง*

## ฟีเจอร์หลัก (Features)

**สำหรับผู้จัดการแข่งขัน (Admin):**
- เพิ่ม ลบ และแก้ไข **ประเภทการแข่งขัน** (ระยะทาง, ราคา, ประเภทแข่งขัน/การกุศล)
- เพิ่ม ลบ และแก้ไข **กลุ่มรุ่นอายุ** (Age Group) ของแต่ละประเภทการแข่งขัน
- เรียกดูภาพรวมและข้อมูลการสมัครของนักวิ่ง
  
**สำหรับนักวิ่ง (Users):**
- สมัครสมาชิกและเข้าสู่ระบบ (ระบบตรวจสอบความถูกต้องของ Email และเบอร์โทรศัพท์)
- ดูรายการแข่งขันมาราธอนที่มีให้ลงทะเบียน
- เลือกลงทะเบียนการแข่งขัน (เลือกระยะทาง, ทีม/ชมรม, ไซส์เสื้อ)

## เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** HTML5, CSS3, Bootstrap (UI & Responsive Design)
- **Backend:** PHP 
- **Database:** MySQL


##  วิธีการติดตั้งและรันโปรเจค (Installation Setup)

เพื่อให้สามารถทดสอบโปรเจคนี้ในเครื่องคอมพิวเตอร์ของคุณ (Localhost) โปรดทำตามขั้นตอนดังนี้:

1. **เตรียมความพร้อม:**
   - ติดตั้ง [XAMPP](https://www.apachefriends.org/index.html) หรือโปรแกรมจำลอง Server อื่นๆ ที่รองรับ PHP และ MySQL
   
2. **คัดลอกโปรเจค:**
   - Clone หรือ ดาวน์โหลดโปรเจคนี้ไปไว้ในโฟลเดอร์ `htdocs` (สำหรับ XAMPP)
   - ตัวอย่าง path: `C:\xampp\htdocs\pbru2`

3. **นำเข้าฐานข้อมูล (Database):**
   - เปิด `phpMyAdmin` (ปกติจะอยู่ที่ `http://localhost/phpmyadmin`)
   - สร้างฐานข้อมูลใหม่ชื่อ `pbru2` (Collation: `utf8_general_ci` หรือ `utf8mb4_general_ci`)
   - กดที่แท็บ **Import** และเลือกไฟล์ `pbru2.sql` ที่แนบมาในโปรเจค
   
4. **การตั้งค่า (Configuration):**
   - ไฟล์เชื่อมต่อฐานข้อมูลอยู่ที่ `db/connect.php`
   - ค่าเริ่มต้นถูกตั้งไว้สำหรับ XAMPP (ผู้ใช้: `root`, รหัสผ่าน: `ว่าง`)
   ```php
   $host = "localhost";
   $username = "root";
   $password = "";
   $db = "pbru2";
   
5. **เข้าใช้งานระบบ**
   -เปิดเว็บบราวเซอร์แล้วเข้าไปที่ http://localhost/pbru2

📁 โครงสร้างโปรเจคเบื้องต้น
   ```
      pbru2/
├── css/                # css (Bootstrap)

├── js/                 # js (Bootstrap)

├── add_race.php        # หน้าเพิ่มรายการแข่งขัน (Admin)

├── edit.php            # หน้าแก้ไขข้อมูล (Admin)
├── index.php           # หน้าหลัก (Home)
├── login.php           # หน้าเข้าสู่ระบบ
├── logout.php          # ระบบออกจากระบบ

   ```
